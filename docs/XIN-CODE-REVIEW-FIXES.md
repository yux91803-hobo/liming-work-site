# 小芯代码复核修复

本轮按用户报告的 P0、P1、P2 六个问题逐项处理，原有上线验收不能替代这些边界攻击测试。

## 1. 桥接软链接越界与 TOCTOU

已修复：先打开且固定 io 目录 fd，所有目录项操作通过 `/proc/self/fd/<fd>` 完成；请求以 O_NOFOLLOW / O_NONBLOCK 打开，fstat 与限量读取使用同一个 fd。回复在执行桥操作前独占创建，O_EXCL / O_NOFOLLOW，权限 0600；不覆盖任何已有条目。目录路径被替换也不改变操作所用 inode。

攻击回归包括：恶意 reply 软链接、请求验证后替换、io 路径替换、打开请求后换文件。旧实现四项均失败，新实现四项均通过。攻击目标全部是专用测试文件。

其余问题继续在后续修复中记录：发送切会话、快速回复重复提问、独立复核模型硬约束、非标准 STM32 工程、组长退出后的孙进程清理。
