# 天启工作台：照 Linear 改版（设计）

## 为什么

站长 11-20 问「参考 Linear 官网的设计，打算怎么改进天启的 UI」。看过模板（Design 画布：现在 vs 改后，电脑 / 手机 × 夜空 / 星图）以后说「改吧……直接做」，另外点了几处：
- 插件页不要现在那样：半透明浮层，后面的字透过来，底下空一大块。
- 再按 Linear 看一遍整体布局。

手机键盘、上下文和 token 两个 bug 在前一个 PR 修了，这里只管界面。

## 参考

- **Linear 官网的样式**（2026-11-20 抓的 CSS 变量）：
  - 背景四层近黑 `#08090a / #0f1011 / #141516 / #191a1b`，三档阴影全是 `none`，边框是 5% / 8% 的白。
  - 文字四级 `#f7f8f8 / #d0d6e0 / #8a8f98 / #62666d`，点缀色只有一个。
  - 字重 510 / 590，标题字距 -0.012em ~ -0.022em，圆角按 4 / 6 / 8 / 12 / 16 分档。
- **Linear 讲自己改版的文章**（How we redesigned the Linear UI, part II，2024-03）：
  - 收拾侧栏、标签、标题栏：减少视觉噪音，增加层级和密度。
  - 侧栏和标签里的文字、图标、按钮横竖都对齐。
  - 层次靠黑白的透明度；减少底色里掺的品牌色，回到中性、耐看；提高正文和图标的对比度。
  - 标题用 Inter Display，正文用 Inter。
- **命令面板**：Linear 的 Cmd K（开源的同类是 pacocoursey/cmdk）。分组，方向键加回车，每项右边写快捷键。单键快捷键只在没在打字的时候生效。

## 做什么（和模板一致）

1. **层次**：左右两栏和各种弹层改成实心的分层面板，边上一条 1px 半透明细线。去掉毛玻璃（`backdrop-filter`）、大阴影（`0 28px 80px`）、内高光（rim）和金色光晕（glow、`drop-shadow`）。弹层只比面板亮一档。
2. **颜色**：点缀色只留金色（天启的星），只用在选中、发送、在线、焦点这几处。计划的蓝、风险的橙收成小面积的状态色（小圆点、文字）。不用 Linear 的靛蓝，那是它的品牌。
   - 夜空（深色）：
     - 面板 `#0d0e12`，抬高一档 `#15161b`，弹层 `#1b1d22`；
     - 细线 `rgba(255,255,255,.07) / .12`；
     - 文字 `#f1f2f4 / #c9ced7 / #9aa0ab / #7d838e`；
     - 金 `#f0d79c`。
   - 星图（浅色）：
     - 面板 `#fff`，抬高一档 `#f5f6f8`，弹层 `#fff`；
     - 细线 `rgba(16,20,30,.08) / .14`；
     - 文字 `#111318 / #373d48 / #5d636e / #6e7480`；
     - 界面上的金色用 `#b0852a`；发送键用深墨色，因为金色在白底上太淡。
3. **字**：
   - 用系统字体：苹果上是 SF Pro 加苹方，Windows 上是 Segoe UI 加微软雅黑；装了 Inter 就先用 Inter。
   - 不从 Google Fonts 加载：国内打不开，会卡住页面。
   - 标题字重 600、字距收紧；左栏和标签 13～13.5px，正文 15px。
   - 「天启」两个字照旧用宋体。
4. **圆角**：面板和弹层 12px，按钮和列表行 6～8px，输入框 12px；不再用 18～22px 的大圆角。
5. **对齐和密度**：
   - 左栏每行一样高（32px），图标一样大（16px），日期右对齐、数字等宽；分组标题用三级灰的小字。
   - 顶栏是「工作区 / 对话标题」一行，不再是两块胶囊。
6. **动效**：短而准（120～200ms，减速曲线），标签下划线不回弹；流星少一些；进了对话以后夜空暗一点。系统开了「减少动态」时照旧全关。
7. **插件页**：
   - 实心面板。电脑上居中（440px）；手机上从底部升起，高度跟着内容走，顶上一条拖动条。
   - 每行：名字、一句说明、开关（开着是金色）；读取中、读取失败都写清楚。
8. **命令面板（Ctrl K）**：
   - Linear 那样分组，每项右边写快捷键。
   - 天启补上常用操作：换模型、换权限、计划模式、切换工作区、打开终端、左栏、右栏、插件、设置。
   - 单键快捷键：C 新建对话、M 模型、P 权限、W 工作区。只在没在打字、也没按 Ctrl / Alt / ⌘ 时生效（同 Linear）。
9. **手机**：
   - 顶栏是菜单、标题（下面一行小字写工作区）、命令、右栏四样，能点的地方都不小于 44px。
   - 输入框里的按钮一行放下；模型名放不下时省略。

## 不做

- 不改功能，不改控制器。这个 PR 只动前端。
- 不搬 Linear 的配色、字体文件、图标和图形，只学它的做法。
- 不动小芯的工作台：样式都限定在天启模式（`.tq-mode`）里。`chat.js` 只加天启要的挂载点，比如命令面板里天启的操作、每项的快捷键。

## 留给实现的

- 具体选择器、各组件的间距按上面的数值定，和模板对着截图调。
- 浏览器测试里检查老样子的那些项（玻璃、光晕）按新样子改，并新加几项：
  - 面板没有 `backdrop-filter`、没有大阴影；
  - 插件页在手机上贴底、不透明；
  - 命令面板里有天启的操作和快捷键；
  - 单键快捷键在输入框里不触发。
