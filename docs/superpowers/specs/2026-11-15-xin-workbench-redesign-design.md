# 小芯工作台重新设计（2026-11-15）

站长原话：「当前这个工作台的 UI 有点丑，而且还有点简陋」「功能丰富，界面美观，交互好看」「从 0 设计……看现有代码实现了哪些功能，可以加新的布局，有些你觉得不需要的就删掉」「我看中的是交互细腻和好看，要让人看着很舒服，很美观」。

实现与自查：Claude Code。参考：impeccable（操作型界面的规则、craft floor）、anthropics 的 frontend-design（避开模板化的默认风格）、ui-ux-pro-max（交互与可访问性规范）。

## 1. 为什么要改

旧界面的问题（对照截图 2026-11-15）：

- 像一套通用模板：所有东西都是同一种圆角白卡片和细边框，层级只靠边框分；奶白底配陶土橙，正是 frontend-design 点名的 AI 默认配色。
- 小芯的回答套在带边框的气泡里，代码块、表格在气泡里再套一层框，手机上被挤得很窄。
- 手机标题栏五个小图标挤在一起；状态（在线、在忙、额度、任务数）分散在标题小字、输入框上方的条、右栏、头像光环四处。
- 右栏常驻 340px，只是任务列表；欢迎页只有一个头像和一句话。
- 交互没有手感：开关面板、展开任务、复制都是瞬间切换或者千篇一律的淡入。

新加：

- **小芯岛**：标题栏正中一颗黑色药丸，是小芯本身——它的像素脸、现在在干什么、在做几件事、几件等你。点开从药丸里长出一块面板：它的电脑（在线 / 休息、看屏幕）、额度、进行中 / 待处理 / 成果。
- **命令面板**（Ctrl / ⌘ + K）：搜对话、开新对话、回主对话、每日任务、小芯的屏幕、用量、小芯的文件、设置、换主题。
- 侧边栏「搜索」（就是命令面板）、每轮回答「复制」、代码「换行」和折叠、回到底部（有新消息时标出来）、操作结果的轻提示（已改名、已归档、换主题……）。
- 小芯的表情：等你打字时低头看、想事情抬眼、在电脑上忙时侧身、做完开心、出错难过、睡着闭眼；登录输密码时闭眼不偷看。

## 3. 设计方向：「芯片与纸」

依据：小芯本身的材质——黑色倒角芯片、银白顶边、暖金属引脚、暖白发光的眼睛（mascot.js 的配色）。

- **纸**：你的东西（对话、你说的话、输入框、侧边栏）在柔和的纸面上，浅色是带一点暖的灰白，深色是暖黑。
- **芯片**：小芯的东西（小芯岛和它展开的面板、钉在右边的工作台、代码块——它电脑上的输出）用黑色芯片材质，顶边一道银白细光，像它的身体。
- **眼光**：唯一的强调色是小芯眼睛的暖光（琥珀色）。只给「活着的」东西用：小芯在干活、正在进行的任务、当前选中、焦点。按钮主色是芯片黑（深色主题里是纸白）。

不用：陶土橙、奶油底配衬线大标题、渐变色块、同一种圆角卡片铺满、全大写小标签。

### 色板

| 名字 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 纸 | #F6F5F2 / 面 #FFFFFF | #121110 / 面 #1B1A18 | 底和内容面 |
| 墨 | #1C1B19 / 次 #57534D / 弱 #736E66 | #F2EFE9 / 次 #B5B0A7 / 弱 #8D887F | 文字 |
| 芯片 | #171614（渐变到 #22201D） | #050505（渐变到 #161513） | 小芯岛、工作台、代码块 |
| 眼光 | #F4B74A（文字用 #8A5A0F） | #FFCB6B | 活跃、焦点、进行中 |
| 待处理 | #D9622B | #FF8A5C | 等你处理 |
| 好了 / 失败 | #2F8A57 / #C5432E | #7BD3A0 / #F27B62 | 结果 |

### 字

- 正文和界面：系统中文字体（苹方、HarmonyOS Sans、MiSans、微软雅黑、Noto Sans CJK），数字等宽对齐。不加载网络字体（站长在国内用）。
- 代码：系统等宽字体。
- 点阵字（站内 Unifont 裁剪版）只在一处用：欢迎页那句「嗨，我是小芯」，和小芯的像素脸放在一起。

字号：12 / 13 / 14 / 15（正文）/ 17 / 32（欢迎）；手机正文 16。

### 形状和层级

圆角按层级分：小芯岛全圆；输入框 22；面板、工作台 18；代码块 12；按钮 10；小标签 8。两级阴影：浮起（输入框、菜单）和悬浮层（面板、命令面板）；深色主题加一道顶边细光代替阴影。

### 动效

- 时长：按下 120ms、状态 180ms、面板 260ms、小芯岛展开 340ms；退出是进入的 70%。
- 曲线：进入用减速，离开用加速；小芯岛展开用一点弹性。
- 像素东西（指示灯、进度格、小芯眨眼）用逐帧（steps）。
- 都能被打断；系统设了减少动态就不做位移和弹性。

## 5. 交互细节

- 小芯岛：按下微缩；展开时面板从药丸的位置长出来（clip-path + 位移，弹一下），内容淡入；收起比展开快。脸每隔几秒眨一下眼；在忙时侧身敲键盘（逐帧）；有事等你时右边的数字是待处理色。
- 输入框：聚焦时一圈眼光色的柔光；打字时小芯岛里的小芯低头看；发送键在没字时变淡，有字时变实；小芯在回话时，空着是「停止」，有字是「排队发送」。
- 新消息：你的话从输入框方向升上来；小芯的回答淡入并上移几像素；「正在输入」的位置就是回答出现的位置。
- 回答：每轮最后一条下面一个小的「复制」，复制这一轮小芯说的全部原文（Markdown）；手机上只露图标；复制后变成对勾和「已复制」。（实现时定的：原来想电脑上悬停才出现，但悬停对键盘和触屏都不友好，一轮只露一个就不吵。）
- 代码块：头部写语言，右边「换行」「复制」；超过 24 行先收起，底下渐隐和「展开全部 N 行」。
- 往上翻时右下角出现「回到底部」，下面来了新内容时写「新消息」。
- 侧边栏：当前对话有底色；顶上「搜索」打开命令面板（实现时定的：和命令面板合成一个，不再另做一个只能搜对话的框）；⋯ 展开改名、归档、删除，删除要点两下。
- 命令面板：从中间放大淡入；上下键选、回车执行、Esc 关；没搜到时写「没有找到」并给出能做的事。
- 轻提示：底部中间一颗小药丸，3 秒消失，不抢焦点。
- 登录：小芯在卡片上方，输密码时闭上眼睛，登录成功笑，失败眨一下眼。

## 6. 测试

浏览器测试按类名和行为核对，结构变化的地方跟着改，检查的行为保留：

- 删掉的入口（任务条、任务列表页、方格按钮、标题栏屏幕按钮）对应的检查改成检查小芯岛：显示在做几件、待处理几件，点开能看到同样的分组和任务，能修改、停止、回复，能打开屏幕。
- 布局检查改成新的尺寸：电脑默认两栏（侧边栏 + 聊天），钉住后三栏；平板一栏 + 钉住；手机小芯岛面板在屏幕内、不横向溢出。
- 新功能加检查：命令面板（打开、焦点、搜对话、回车切换、Esc 只关它且焦点回去、换主题有轻提示）、复制整轮回答和代码、换行、代码折叠、回到底部、小芯岛展开和钉住；输入框里打「/」不被首页搜索抢走、学习台开着时 Esc 只关聊天（实现时发现的老问题，一起修）。

## 7. 不做的事

- 不改发送、排队、待送达、轮询、SSE 这些逻辑。
- 不加载外部字体和脚本。
- 不改 mascot.js 里小芯的动作，只给头像加一个能画不同表情的参数。
