# 小芯工作台动画：修逻辑问题，做得更新颖好看

状态：站长已确认（北京时间 11-19 凌晨，「做吧，兄弟支持你」，方案 1–7 全做）。

## 为什么

站长 11-18：「检查一下当前工作台还有哪些动画逻辑不合理的地方，有哪些动画可以改进的，动画尽量要创新，新颖，好看特效多一点」。

我把手机和电脑上的整套操作逐帧截了下来看：打开工作台、发消息、派活、打开和关闭终端、整理结果、结果出来、侧边栏。截图方法是浏览器截屏流，按时间拼成图。

## 发现的问题

1. **直接打开工作台会先闪一下首页**：链接带 `#xin-work` 时，首页先露出约 0.3 秒，再硬切到工作台。
2. **结果出来是硬跳的**：从任务轮询那条路画结果时，结果没有进场动画，任务框瞬间跳到下面。
3. **在做的小方点节拍完全一样**：侧边栏、卡片、小芯岛上的 `xcpix`、`xwblink`、`tmblink` 都是 1 秒硬闪，同一节拍，显得机械。
4. **小芯岛靠改 `width` 做伸缩**：每一帧都要重排版，手机上容易掉帧。

## 要做的（画风统一用小芯的像素风）

1. **首页进工作台**
   - 修掉闪首页：`index.html` 头部看到 `#xin-work` 就先把首页藏起来，工作台出来再放开，最多等 3 秒。
   - 从首页点进工作台时，用 View Transitions 做像素格溶解；不支持的浏览器照旧直接打开。
2. **发消息**
   - 你的话从输入框飞上去，变成气泡（FLIP：从输入框的位置和大小移到气泡的位置）。
   - 小芯的回答一段段淡入，段与段之间隔一点；整条有一道微光扫过。
3. **派活**
   - 任务框出现时，从左到右一格一格搭出来。
   - 在做的时候，一颗像素小彗星绕着框边跑（`@property` 的角度加 `conic-gradient`，只留边框那一圈）。
   - 做完时 ✓ 盖章：放大落下并转一下，迸出几颗像素火花。
   - 结果文字淡入，任务框平滑滑到下面（FLIP）。这一条同时修掉问题 2。
4. **终端**
   - 电脑上打开时像老式显示器开机：先亮一条横线，再展开成整屏，带扫描线闪一下。关上时缩成一条线，再缩成一个点。
   - 手机上照旧从下面滑上来，内容带一下扫描线闪烁。
5. **小芯岛**：派出新活、活做完时鼓一下，再亮一圈光（往外扩散的光环）。
6. **小方点**：改成呼吸式的明暗，各自错开节拍。
7. **深浅色切换**：从点的那个按钮开始，一圈扩散着换颜色。用 View Transitions 的圆形揭开，分几步走，带像素感。

系统开了「减少动态」时，以上全部关掉，只留必要的淡入淡出（已有的规则照旧）。

## 不做

- 不改动画以外的行为、排法和文案。
- 不引入动画库，只用 CSS 和原生 Web Animations。
- 小芯岛的 `width` 伸缩这次不换做法：换的话要改岛的结构，风险大。只加鼓一下和光圈；`width` 掉帧的问题记在交接记录里。

## 参考

- FLIP 做法：Paul Lewis 的「FLIP Your Animations」，Framer Motion 的 layout 动画也是这个思路。
- 主题切换的圆形揭开：Telegram 的主题切换、`document.startViewTransition` 的官方示例。
- 灵动岛：小芯岛在苹果灵动岛的弹性和发光上做像素化。
- 边框光点：用 `@property` 动画角度做 `conic-gradient` 的边框光，是常见做法。
