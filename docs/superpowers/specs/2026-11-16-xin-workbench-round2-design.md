# 小芯工作台第二轮（2026-11-16）

站长看了 #150 上线的新工作台后提的六件事（原话摘要）：

1. 「我不希望他用这种方式回答我，我想让他直接把原话转达给我发到聊天里，这种属于我问他问题，他还个卡片让我点进去看。」（截图：问电脑上的 agent 配了哪些模型，回来一张「查看本机agent模型配置 / 我做好了…结果和验证记录已经保存，可以打开详情查看 / 用时 2 分钟 / 查看详情」的卡片）
2. 「黑色药丸做得挺好的，但是里面细节动画过度还需要优化……有的地方卡卡的。」
3. 「天启模式我不想放在设置里面，因为它属于另一种 agent 形式。你来想想怎么搞一个新的 UI。他里面可以选模型的思考强度，可以参考一下 agent 选择思考强度的那种 UI 动画。」
4. 「用量，我希望你把网关和谷歌的分开。」
5. 「搞一个实时展示小芯干活的命令行动画，UI 设计可以参考 Claude Code 命令行……现在显示的不是思考中么，改完之后就会显示实时的那个终端界面……显示他敲的代码，或者显示的网页啥的，当然不是把他电脑上真实展示的画面搬过来。」
6. 「现在小芯不管干啥，他都是显示思考中，你可以参考 grok bot 思考的时候会显示各种字。」

实现与自查：Claude Code。分两个 PR 上线：第一个做 1、2、4、6，第二个做 3、5。

## 1. 问题的答案直接说在聊天里

**原因**：后台做完后，前台小芯写交付消息，控制器的 `publicCompletion`（`site/xin/vm-handoff.mjs`）有一道防泄露过滤：消息里只要出现 kimi / deepseek / glm、「分身」或「任务 N」，就把整段换成「我做好了：…可以打开详情查看」。站长问的正是模型配置，答案里必然有模型名，于是真答案被整段丢了；网页再把它画成带标题、用时、「查看详情」的卡片。

**改法**：

- 过滤只管该管的：站长的原话或任务标题问到模型、配置、agent、实现时，模型名就是答案本身，不过滤（README 原有规则「直接询问实现时如实回答」）。内部编号只认这一件活自己的编号（`任务 3` 这种，免得误伤 RTOS 里的「任务 1」）和「分身」；括号里的整段去掉，其余按句去掉提到它们的句子，答案留着；全去光了才退回后台自己的结果原文，再不行才说「我做好了：标题。」，不再叫人去看详情。
- 交付提示词：问题、要查的东西，把查到的内容完整带上（列表、数值、配置、路径、代码照原样写），不要省成「已保存」「可以查看详情」；做的是活，说结论、关键细节、路径或预览、要他做的事。
- 网页：结果画成普通的小芯消息（和别的回答一样能复制），不再有卡片的标题、边框和「查看详情」大按钮。下面一行小操作：复制、详情（打开任务详情；站长看过后定叫「详情」）；要你批准 / 登录 / 回答时多一个主按钮；网页成品多一个「打开网页」。第二个 PR 里回答上方再加可展开的工作记录（见 5），「详情」留着。

## 2. 小芯岛的动画

**卡顿的具体原因**（看代码、逐帧截图找到的）：

- 面板展开时药丸瞬间消失、收起时药丸瞬间出现，和正在缩回去的面板叠在一起闪一下。
- 面板用 clip-path 裁形状，把自己的阴影也裁掉了；展开过程中药丸里的内容和面板标题位置对不上，第一帧跳一下。
- 弹性曲线过冲（cubic-bezier 的 1.32），边缘抖。
- 打开时立刻去取任务和额度，数据在动画途中到达，整块列表重画；之后每 4 秒轮询也整块重画，进行中那条细进度光每次从头跑。
- 药丸里的状态字一变，宽度直接跳；数字徽标直接出现。

**改法**（参考 cult-ui 的 Dynamic Island：弹簧 stiffness 400、damping 30，内容进场「透明 + 缩到 0.9 + 下移 5px」、退场带 blur；Vaul 的 iOS 曲线 cubic-bezier(0.32, 0.72, 0, 1)）：

- 共享元素：药丸里的「脸 + 小芯 + 状态 + 数字」和面板标题左边那组排成一模一样，展开时这一组从药丸的位置移到面板标题的位置（FLIP，只动 transform），形状同时从药丸长成面板；收起反过来，形状缩回药丸那一刻再把药丸换回来，换的那一帧两边长得一样，看不出接缝。
- 形状用 clip-path，曲线换成按 400/30 弹簧采样的 CSS `linear()`（不支持的浏览器用 Vaul 曲线）；收起 0.26 秒、加速，比展开快。
- 阴影：展开完再去掉裁剪、阴影淡入；收起开始时阴影先淡出。
- 动画途中不重画；任务列表按内容签名判断，没变就不重画，时间文字原地更新。
- 药丸：状态字换的时候旧字往上淡出、新字从下面进来；宽度跟着平滑变化；数字徽标弹入。
- 系统设了减少动态：不做形变和位移，只淡入淡出。

## 3. 天启：独立的 agent 入口（第二个 PR）

- 设置里的「天启模式」开关去掉。
- 新对话（空白页）上方一个「小芯 | 天启」切换；选天启，空白页换成天启的标志（像素星，冷色星光），输入框里出现模型和思考强度。开始聊以后这个对话就定了是谁；侧边栏和命令面板里有「新的天启对话」。
- 模型和思考强度：输入框里一颗按钮写着模型名和一组像素强度格；点开是模型列表和一条强度轨道（关 / 低 / 高 / 最高，按模型真正支持的档位），拖动、点、方向键都能选，滑块弹簧跟手，强度格逐格亮起，每档一句短说明（参考 OpenAI Codex `codex-rs/models-manager/models.json` 每档 `effort` 配一句 `description` 的做法）。
- 天启自己的强调色只在天启的东西上用（标志、强度格），小芯的琥珀色不混用。

## 4. 用量：网关和 Google 分开

- 控制器的 `usage` 多给一张表：每个模型来自哪里（Google = Antigravity 的 Gemini；网关 = WorkBuddy 网关上的 DeepSeek、GLM、Kimi；其他）。旧控制器没有这张表时网页按模型名猜。
- 用量页：最上面「电脑」（叫醒电脑、状态这一行仍紧跟在下面）；下面「Google | 网关」切换（记在这个浏览器里），各自显示：额度（只有 Google 有）、范围（今天 / 7 天 / 30 天）、合计、每天的柱子、图例和按模型列表，都只算这一边的模型。
- 小芯岛面板里的额度写明是 Google 的。

## 5. 实时终端（第二个 PR）

> 站长看过第一版（终端常驻在聊天最下面、做完收成一行）以后改了方向：「我希望这个终端是我点击小芯聊天里的头像再弹出来的；
> 做得不够好看，可以搞点像素风，和 Claude Code 差不多，它里面有小螃蟹的图案，我们可以搞小芯的图案；
> 代码是一个字符一个字符敲出来的，不是一下冒出一大段。」下面先写最终做法，原来的设想留在后面对照。

**最终做法**（`site/xin/term.js` + `chat.js` 里「小芯的电脑」一节）：

- 点聊天里小芯的头像弹出「小芯的电脑」窗口：电脑上在头像旁边长出来，手机上从底下升起。头像右下角有个像素小终端标记的才点得开（那一次在电脑上真做了事），正在干活时它在闪。
  - 「正在输入」那一行的头像：这一轮正在做的；后台有活在做、前台没在回话时，聊天最下面多一行（和「正在输入」一个样：「编译 blink · 编译中 · 32 秒」），点它的头像看那件活。几件活就分几页。
  - 一条回答的头像：那一轮在电脑上做的，那一轮派出去的活各一页；任务结果的头像：那件活（做完的点开才去取完整记录）。
- 样子：首页那套像素风（方角、2px 粗边框、不模糊的硬阴影、点阵字标题「小芯的电脑」）。里面照 Claude Code：开头一块欢迎框，左边米白像素底上站着小芯的全身像素小人（Claude Code 那里是小螃蟹 Clawd），右边「小芯」、模型、工作目录；「> 要求」一条灰底；每一步「运行(make -j4)」「修改(src/tim.c)」「打开网页(…)」，结果缩在折角线下面；改动一行一行红绿；最底下转圈的星、在干什么、用了多久、Esc 关闭；做完一行「干完了 · 用时 2 分钟 · 4 条命令」，然后闪着的光标。
- 一个字一个字敲：命令、改的代码、输出、说的话都逐字出来。来了新东西就定一个「最晚什么时候敲完」（刚打开重放 1.2 秒、之后 1.5 秒），按剩下的时间匀速敲：积压多了打得快，但不会一下冒出一大段，也不会越拖越慢。刚打开先停 0.36 秒，让欢迎框里的小芯先露个脸。系统设了减少动态就直接画出来。
- 数据：任务摘要带 `run`；后台的活只在窗口开着、正看那一页时才按 `run` 轮询 `poll`（不带设备和标签页，不算在看这个对话、不影响完成通知），取到的存着，关了再开从存着的地方接着取。没用 SSE：前台那一轮已经有流，后台的活只在有人看时取，轮询更省事（1 秒 / 没新东西 1.8 秒一次）。
- 不显示内部命令：`xin` 后面不是 `browser` 的（派活、记忆、交付）一律不画，任务的要求原文（user 事件）不画。

**原来的设想**（第一版照这个做了，站长看后改成上面的）：

- 小芯在这个对话里派出去的活正在做时，聊天最下面出现一个终端：Claude Code 命令行的样子（项目符号、缩进的输出、底部转圈的状态行），在小芯的芯片黑底上。内容来自真实事件：它敲的命令（打字机效果）、输出的前几行、改了哪些文件和改的代码（控制器把 Codex 给的改动差异一起带上）、打开的网页（自己画的地址栏和加载条，不是它电脑的画面）、它中途说的话。
- 数据：任务摘要带上当前轮次编号，网页用现有的 SSE 流（`/api/xin/stream?run=`）跟这一轮，断了退回轮询。
- 做完：终端收成一行「干完了 · 用时 2 分钟 · 4 条命令」，点开能看完整记录；小芯的回答接在下面。天启这种前台自己敲命令的回合也用同一个终端。

## 6. 状态字

参考 gemini-cli 的 `usePhraseCycler`（俏皮话每 5 秒换一句；模型有真实的思考标题时优先显示标题）和 Claude Code 转圈时的动词：

- 在敲命令时按命令说具体的：编译中、跑测试、翻文件、找文件、装软件、看网页、在网页上操作、改代码、搜网页、用插件……
- 只是在想时每 4.5 秒换一种说法（思考中、琢磨中、推敲中、盘算中、酝酿中、捋一捋、想一想、掂量掂量、组织语言、斟酌一下），第一句总是「思考中」，换的时候旧字往上淡出。
- 小芯岛的状态字跟着一起换。

## 测试

检查旧结构的地方跟着改，行为保留，不删测试；新加：过滤不误伤（问模型时保留模型名、内部编号按句去掉、全去光才退回）、结果是普通消息、状态字按命令变化和轮换、用量页按来源分开、小芯岛展开收起时药丸和面板不会同时出现。
