# 小芯下一阶段：长期记忆、电脑操作与底座调整（定稿）

本文是和站长讨论后确定的设计，作为后续开发的依据。实现时以代码和 `docs/CHANGES.md` 最新条目为准，设计有变化同步更新本文。确定日期：北京时间 2026-11-07。

## 1. 定位与边界

- 只有一个小芯：**默认模式**下的小芯是唯一的主脑。后台用不同模型、不同执行器都只是它完成事情的内部能力；用户始终在和同一个小芯说话。
- **天启模式**是独立的高级功能，名字叫「天启」，不是另一个小芯。它保留原有的模型选择、思考强度、插件和其他功能，但不参与小芯的长期记忆、好感度和人格成长，也不复制现有记事本；以后需要再单独讨论它自己的记事功能。
- 本文的新能力（长期记忆、浏览器与电脑操作）只给默认模式的小芯。
- 不做：多智能体群聊、跨用户协作、分身再派分身、并行 worktree、知识图谱数据库、按统计自动调整路由。

## 2. 已确认的决定

| 事项 | 决定 |
|---|---|
| 天启 | 叫「天启」；功能照旧；与小芯数据在功能上完全独立；暂不需要自己的记事本 |
| 每日任务 | 以后改用更安全的浏览器操作（沙盒 + 白名单网站） |
| 网站 | 先从少量低风险网站开始，具体网站以后按实际需求定；密码、验证码由站长自己输入 |
| 记忆来源 | 主要来自站长和默认模式小芯的真实交流；学习台记录、答题情况、经小芯验证的任务结果可作依据；天启聊天不参与 |
| 隐私 | 记忆由站长掌控；敏感信息不自动保存；能看到每条记忆来自哪次对话；纠正、删除后不得从旧聊天或旧摘要中恢复 |
| 原始聊天 | 默认 30 天自动删除；删除原话或历史前先说明影响 |
| 整理时机 | 空闲时或积累一定新对话后整理；有次数和资源上限；不为整理开机，不影响正在执行的任务 |
| 需要确认的操作 | 见 §5.3 |

## 3. 第 0 步：底座

1. **后台沙盒网络隔离**（已验证的问题）：后台 bwrap 容器原先与小芯电脑共用网络，容器内能无密码连上桌面 VNC、无认证连上 X11，`xdotool` 可用；网关和 Antigravity 的本地端口也对容器开放。改为容器独立网络：推理经控制器在任务 io 目录里的本地套接字代理；上网经控制器的出网代理，只允许公网地址的 80/443；编译、网页验收、插件不联网。不改动天启和每日任务。
2. **天启数据隔离**：天启每轮写入 Harness 的设定原先是小芯的完整设定（记事本、好感度、开场白、新动作、每日清单的说明），天启聊天也给小芯加好感度。改为天启使用自己的设定，不读写小芯的个人数据；天启对话不进入记忆整理和回忆检索；清理旧设定副本里的记事本内容。天启的模型、强度、Purge、文件、屏幕等功能不变。
3. **找回默认模式小芯的性格**：前台改为纯推理调度后，`xin say/dance/bond/next/move` 在主聊天里不可用，前台设定也不含关系等级。改为前台的结构化函数（只写小数据文件），设定带上关系等级。
4. **记事本截断**：超过 8000 字时现有代码保留最早的内容、截掉最新的；在记忆 v1 替换前先改为保留最新内容并提示整理。
5. **拆分 `vm-agent.mjs`**：按职责拆成提示词、路由、调度、执行器适配、陪伴功能、推送、对外接口；Worker 改成按清单上传模块。只重构，不改行为。

## 4. 长期记忆

### 4.1 原则

- 原始聊天是证据，不是记忆；记忆是小芯对站长「现在」的理解：少量、有类型、有出处、可修订。
- **准确比数量重要**：只记以后会改变小芯做法的内容；不确定的不当事实；不为了显得了解而猜测或囤积细节。
- 记忆要自然体现在交流、辅导和做事里，而不是只在被问「你还记得吗」时才查。

### 4.2 类型

关于你（称呼、交流偏好、目标）· 学习画像（按学习台章节和知识点）· 我们的经历（带日期和出处的情节摘要）· 我在做的事（项目目标、决定与理由、进度、约定）· 做事方法（反复做的流程、网站做法）· 小芯自己（做过的事、关系里程碑）。

### 4.3 每条记忆是「带证据的判断」

- **依据**分三种：站长明确说的（立即生效，优先级最高）、互动中观察到的（有具体行为证据，积累到阈值才生效）、小芯的推测（只调整细节或引出一个确认问题，不进入「关于你」的确定部分）。
- **范围**：本次对话 / 某个话题或项目 / 长期。「今天简单点讲」只管本次对话。
- **字段**：内容、类型、依据、范围、证据（对话、轮次、原话片段、日期、方向）、有效期（起始、被谁取代）、状态（有效 / 已取代 / 待确认 / 隐私 / 已删除）、最近确认时间。
- 存在控制器的 SQLite 中，纯文本，与模型无关；中文检索用 FTS5 trigram（已在小芯电脑的 Node 22.23.3 上验证可用）；向量检索以后可选、可重建。

### 4.4 判断随站长变化

- 学习进度按时间加权，最近的证据分量更重：后来能独立推导或写出编译通过的代码，就把「不清楚」改为「基本掌握」，旧判断保留为历史；又出错标为「需要复习」，不退回「不会」；久未涉及的判断使用前先轻轻确认。
- 偏好要在不同日子、不同话题里反复出现才成立；随口一句只影响本次对话；明确说「以后都这样」立即生效；长期没再体现或反应说明不合适，降级为「可能过时」，不再强推。
- 站长的纠正立即取代旧判断；站长说「这类事别再推测」，小芯停止此类推测。

### 4.5 记忆怎样自然发挥作用

- 每轮由控制器生成几百字的「和你相处的注意事项」（可照做的提示，不是事实清单），放在本轮上下文，不改系统提示以保持缓存：交流方式、当前学习页对应的掌握情况和常见误解、相关项目状态、到期的约定。
- 自动检索在调用前台前完成，不占前台的工具步数和时限；`xin recall` 升级为跨全部对话和经历检索，返回带日期和出处的片段。
- 派后台任务时，只附上与任务相关、不敏感的习惯（例如代码风格）。
- 主动跟进（复习、约定）有频率上限，可关闭；不刻意说「我记得你……」。

### 4.6 来源

- 站长与默认模式小芯的对话：主要来源。
- 学习台的学习记录和答题情况：作为学习进度依据，由网页上报，设置里有开关（默认开）。
- 经小芯验证的任务结果：记入「做过什么」和项目进度；只有站长自己写的代码或答案才算学习证据。
- 后台任务：只能记录「做过什么」，不能写入任何关于站长的偏好；网页内容永远不能成为个人画像。
- 天启：完全不参与。

### 4.7 防止编造

- 每条提议的记忆必须引用原话，控制器逐字核对引文出现在所引用的那一轮，不符即丢弃。
- 后台任务的「记住」只是提议，只能落到项目记录。
- 好感度只影响说话的亲近程度和主动程度，不能生成或修改记忆；提到共同经历必须有出处。

### 4.8 隐私、纠正与删除

- 永不自动保存：密码、验证码、密钥、证件号、银行卡号；站长明确要求也拒绝并说明。
- 健康、财务等个人敏感信息不主动归纳成长期画像；明确要求记住时标为隐私，不主动提起。
- 记忆页显示每条的内容、依据、来源对话的原话片段和修改历史；可确认、修改、删除、设为隐私。
- 要求忘记某件事时：删除该记忆及其派生摘要，并留下「不再记」标记；整理时遇到相同内容一律跳过，也不得从旧摘要恢复；可选择同时删除相关原话。

### 4.9 原始聊天保留

- 默认模式的对话在整理过并且 30 天未再活动后自动删除原话；可单独标记长期保留。
- 删除范围包括对话记录及其在数据库、Codex 会话记录、通知队列中的副本。
- 记忆保留一两句引文、日期和对话标题，原话删除后仍能看到出处。
- 天启记录不受影响。
- 第一次对现有对话启用前，先列出将删除的对话和影响，等站长确认；之后删除原话或历史的操作也先说明影响。

### 4.10 整理时机与上限

- 不固定时间。**轻整理**：一段对话安静下来且新内容达到阈值时，只处理这段新内容。**深整理**：待处理内容足够多或距上次超过一周时，在空闲窗口合并、淡化、更新核心判断。
- 不为整理唤醒电脑、不续活动租约；只在电脑本来就醒着的空闲尾段运行，每次控制在一两分钟内。
- 优先级最低：有用户消息或后台任务时让开；被暂停或中断后从断点继续，处理过的内容不重复。
- 每天有次数和 token 上限；每次只做小改动并保留版本，可回退；一次深整理可改动的条目有比例上限，超过留给站长确认。
- 当前实现默认值：安静 45 秒，轻整理为 600 个新字符或 2 轮，深整理为待处理内容 4,000 字或超过一周；每天（北京时间）4 次 / 48,000 token，单次请求 65 秒（含等待不超过 110 秒）。深整理每次最多让现有有效判断的 20% 生效（最少 1 项），其余待确认。观察的阈值为至少 2 个不同日期、不同话题；敏感原话整段跳过，不主动归纳。
- 纠正留历史及版本；忘掉清除取代链、引文与版本，旧来源轮次被阻止再用。纠正只让旧证据失效，之后新的明确自述仍可说明站长又改变了偏好。控制器的 `restoreMemoryVersion` 是显式回退入口，模型不能调用。


## 5. 浏览器与电脑操作

### 5.1 结构

- 浏览器由控制器拥有：Playwright 驱动电脑上的 Chromium，登录资料目录只由控制器访问，不挂进容器；CDP 走管道，不开端口。执行器只拿到每任务一个临时令牌的「浏览器代理」，代理检查网站范围、动作等级和预算并记录每一步。
- 浏览器开在桌面上，沿用现有「屏幕 / 接管」随时观看和接手。
- 观察以页面结构快照和元素编号为主，页面变化只给差异；画布、验证码等才截图给能看图的模型。桌面软件以后再做，同样走控制器一侧的代理和审批。

### 5.2 两种浏览

- **公开网页的浏览和查询**：任何网站，自主完成；使用不保存登录的干净浏览器，用完即清。
- **需要登录的网站**：只在站长加入白名单的网站使用保存的登录；先从少量低风险网站开始。遇到登录框自动停下，提示「需要你登录」，站长接管输入后「交还小芯」继续。

### 5.3 确认规则

- **必须先确认**：付款；删除重要内容；修改账号安全设置；以站长名义发送消息或发帖；授权第三方应用；修改个人资料；重要项目的部署、公开发布；其他可能产生明显外部后果的操作。确认卡片附截图和说明。
- **自主完成**：普通浏览、查询、截图、下载公开资料和其他低风险操作；不为每个普通按钮询问。
- **任务内授权**：站长对某个具体任务明确授权了某类操作，小芯在授权范围内连续完成，不再反复询问；超出范围或情况变化时再问。
- 等级由代理根据页面元素（密码框、支付/删除/发送按钮等）独立判断，与模型声明的意图不一致时按更高等级处理。

### 5.4 稳定与恢复

- 页面跳转后编号失效即重新快照；完成与否由控制器按页面状态核对，不采信模型口头结论。
- 执行器轮次结束或停下提问时页面保留；有后果的动作记入带幂等键的「已执行动作账本」，续接时不重复；电脑重启后按最后网址恢复标签页。站长接管期间暂停自动操作。
- 成功的流程存为「网站做法」，下次先照做，某步失败再探索。

## 6. 天启的权限风险与可选方案

天启以完全放权运行（同一 Linux 用户、可用免密 sudo）。功能隔离保证天启平时拿不到、写不进小芯的数据，但技术上它仍能读写这台电脑上的任何文件。实际风险主要来自两种情况：天启处理了带恶意指令的网页或文件，或者模型误操作；这时它可能读取或改动小芯的记忆和对话、读取网关密钥、改动控制器脚本。

| 方案 | 做法 | 对天启的影响 |
|---|---|---|
| A 功能隔离（第 0 步做） | 不再注入、不再写入小芯数据；对话不进入记忆 | 无 |
| B 检测与恢复（建议随后做） | 控制器启动时自检脚本内容与文件名中的摘要；记忆库保留版本、可导出；天启命令触及小芯目录时记录并提醒 | 无；只能发现和恢复，不能阻止 |
| C 隐藏小芯目录 | 天启运行在把小芯私有目录替换为空目录的挂载空间 | 日常基本无感；有 sudo 仍可绕过，只防误操作 |
| D 严格隔离 | 天启改用独立用户、无 sudo（或容器） | 不能再装系统软件、管理系统服务，访问共享文件需调整权限，改变「完全放权」 |

建议：先做 A，再做 B；只有当天启经常处理不可信内容，或小芯的记忆变得足够敏感时，再考虑 D。是否采用 C、D 由站长决定，不为隔离直接削减天启现有能力。
