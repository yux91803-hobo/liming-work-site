# 平板（DSH Go）

在自己的安卓平板上装原版 [DSH Go](https://github.com/ccch1mneyyy/dsh-go)（DeepSeek Harness 的安卓 App），再接上自己的网关和 li、li2 两台云电脑。这是第一步，不改 App 本身；第二步 fork 改界面，以后单独设计。设计见 [specs/2026-11-25-tablet-dshgo-design.md](superpowers/specs/2026-11-25-tablet-dshgo-design.md)；平板 AI 自己调用 li、li2 见 [specs/2026-11-26-tablet-cloud-tasks-design.md](superpowers/specs/2026-11-26-tablet-cloud-tasks-design.md)。

## 用起来是什么样

- **打开就说话**：本机引擎一启动，网关就跟着起来，十几秒内能用。模型是网关里的 DeepSeek V4.1 Flash、GLM-5.4、Kimi K3.1 Pro，都能看图。不经过云电脑，所以不用等它们醒。
- **签到**：网关每次启动 10 秒后巡检一次，当天还没签的账号会签上。所以哪天打开过 App，那天就签了。
- **让它动平板**：「设置 › 手机操控」打开后，它能读屏、点按、输入。任务开始前确认一次，随时能停；密码、验证码、付款交还给你。
- **重活交给云电脑，不用切主机**：一直在本机聊。长任务、写代码和编译、查资料写报告、要用云端浏览器的事，平板 AI 会自己派给 li 或 li2，派完接着和你聊，不干等。输入框上方一行显示云端在做什么，点开是「云端任务」面板：每件任务的状态、用时、最近几步、结果，可以插话、停止、接着做。做完它会在对话里告诉你。li 上有 STM32 编译环境，相关的活会派到 li。详见下面「云端任务」。
- **手动切主机只留着调试**：对话列表底部点主机名还能切到 li2、li，日常用不着。

## 第一次装

只有这几步要自己动手：

1. **装 App**：从 [GitHub Releases](https://github.com/ccch1mneyyy/dsh-go/releases/latest) 或 go.dshtui.com 下载 arm64 的 APK 安装。首次启动选「本机」，等运行环境装好。然后到「设置 › 隐私与分享」关掉「发送匿名使用统计」。
2. **建 SSH 令牌和 key**：li2、li 在两个不同的 InstaBox 账号里，每个账号各做一遍：
   - SSH 令牌：打开那台机器，进 Connect → SSH tokens → Create token，选不过期，复制那一行 `ssh ibssh_…@…`。
   - 只读 key：后台「API keys」新建，**只勾 `machines:read`**。平板用它看机器醒没醒、本轮还能跑多久、冷却到几点，不会叫醒机器。不建也能用，只是挑机器时那台按「状态未知」算。
   - 写 key：再新建一把，**只勾 `machines:write`，千万别勾 `machines:delete`**。它只存到那台云电脑上，任务跑着时持有活动租约，不让机器在 AI 长时间思考、没有输出时被当成空闲暂停。不建也能用，只是那种时候可能被暂停。
3. **跑装机脚本**：在 App 里打开一个对话 → 全部功能 → 终端，粘贴

   ```
   apt-get update && apt-get install -y curl && curl -fsSL https://liming-work.com/tablet/setup.sh | bash
   ```

   App 里的 Linux 是精简版，一开始没有 curl，所以这一行先用 apt 装上它，再下载装机脚本。

   按提示依次粘贴 li2 的令牌、只读 key、写 key，再粘贴 li 的三样；不接 li 就在问 li 令牌时直接回车，key 不想给也直接回车。粘贴时屏幕上不显示。
   - 令牌和只读 key 存在平板的 `~/.liming-cloud/secrets.json`（权限 600），给云端任务插件连 li、li2 用。
   - 写 key 不存在平板上，只经 SSH 存到那台云电脑的 `~/.liming-cloud/lease.key`（权限 600）。
   - 重跑时直接回车，就保留原来的 key。

   脚本最后会打印 li2、li 的启动命令和工作目录，以及哪台装了写 key。
4. **加网关账号**：「设置 › 本机引擎」点重启。然后用平板浏览器打开 `http://127.0.0.1:8788`，用 `admin` 登录。
   - **先改密码**：平板上别的 App 也能访问这个地址。
   - 再加网关账号。平板用自己单独的账号，别和 li2 共用一个，两个 IP 同时用容易被风控。
   - 最后在「设置 → API Key」新建一个 key。网关刚装好时不检查 key，建了以后才要求带 key。
5. **加渠道**：「设置 › 模型 › 添加渠道」，按下面两张表填。
6. **加主机（可选，只为调试）**：日常不用切主机。想手动连上去看看时，「切换主机 › 管理远程主机 › 添加 SSH 主机」，按下面的表填，填完关掉「连接上次使用的主机」。
7. **打开手机操控**：「设置 › 手机操控」打开开关，按页面提示开无障碍和通知。侧载的 App 开不了无障碍时，点「无障碍开关点不动？」，按手机品牌的说明「允许受限制的设置」。

| 项 | 填 |

## 云端任务（平板 AI 调 li、li2）

**怎么派**：直接跟平板 AI 说要做的事。它判断是长任务、写代码、查资料、要用云端浏览器时，用 `cloud_run` 派出去，马上回你「已交给 li2，任务 t_…」和挑这台的理由，然后接着聊。想点名机器、接着某个任务做、换模型，跟它说就行（模型可选 DeepSeek V4.1 Flash、GLM-5.4、Kimi K3.1 Pro，默认 DeepSeek）。

**怎么挑机器**（不用管，理由会写在回复里）：
1. 正在冷却的不用（冷却期间怎么都叫不醒）；两台都在冷却就不派，告诉你最早几点能用。
2. 本轮剩不到 45 分钟的靠后；只剩它能用时照派，并提醒「大约 N 分钟后会暂停，到时任务冻结，冷却结束后接着跑」。
3. 接着原来的任务、同名项目回原来那台；STM32 的去 li。
4. 醒着的优先（省约 40 秒唤醒）；再看平板在那台跑着几件，少的优先；还一样就挑最久没用的。
5. 每台同时最多 2 件平板任务，在「云端任务」面板最下面能改（1–5）。

**看进度、插话、停止**：
- 输入框上方一行：「li2 进行中 · 7 分钟」「li2 剩 25 分钟」「li 冷却到 14:20」「1 件云端任务完成（未读）」。点它打开面板。
- 面板在聊天页（弹层）和对话详情的「插件」页签：每件任务一张卡，展开「插话」写一句发给云端（这一轮还在跑就插进去，做完了就在原来的云端对话里接着做）；「停止任务」要确认。
- 也可以直接跟 AI 说「看看云端那个任务」「停掉它」，它用原生的 `job_output`、`job_kill`。

**平板睡了、App 关了**：云端照常跑，不受影响。你回到那段对话时，平板接上：已经做完的会补说一次结果（只说一次），还在跑的接着跟。停止也一样：停到一半断了，面板显示「停止中（正在确认）」，连上后接着停，确认云端那一轮、后台命令和项目目录下的进程都停了才说「已停止」。插件叫不醒没打开的对话，所以结果要等你回到那段对话才说。

**云电脑的规矩**：平板派来的活都在 `/data/workspace/tablet/<项目>` 下，用 li、li2 上的 `web` 配置，不碰小芯、天启的目录和 `headless` 配置。跑着时有租约，不会因为没输出被暂停；免费版一轮最多 120 到 480 分钟，到了照样暂停、冷却，所以长任务会被提醒。

**平板丢了**：去两个 InstaBox 账号的后台，吊销两台的 SSH 令牌、两把只读 key、两把写 key。

### 真机验收（装好后对照）

1. 让 AI「在云电脑上查一下 FreeRTOS 和 RT-Thread 调度的区别，写一份对比」：几秒内回「已交给…」，状态条出现，做完对话里告诉你结果。
2. 任务跑着时在面板里插一句话、再点停止：插话进了同一轮；停止后面板显示「已停止」。
3. 派一个要 40 分钟以上的活，锁屏离开 40 分钟再回来：云端没被暂停（有租约），回到对话时补说结果，只说一次。
4. 什么都不派、空闲 30 分钟：li2、li 照常睡（租约放掉了）。
5. 网站上的小芯、天启照常用。

## 别做的事

- **别点「设置 › 本机引擎 › 重置运行环境」**：它会删掉 `/root`，网关和账号一起没了。真要重置，之后重跑装机脚本、重新加账号。
- **连上 li2 时别接着天启的对话**：天启的对话回网站继续。平板上只在 `/data/workspace/tablet` 里开新对话，免得两边同时写同一个对话。
- **手动连上云电脑用完切回「本机」**：一直连着 li2，它就不睡；到了免费版连续运行的上限（120 到 480 分钟）会被冷却，那段时间天启也用不了。（AI 派活不需要切主机，做完会自己放手。）
- **别把写 key 勾上删除权限**：写 key 只需要 `machines:write`。

## 出问题看哪里

- 网关日志在 `/root/workbuddy-gateway/logs/gateway.log`，插件日志在同目录的 `plugin.log`。
- 插件 10 分钟内重启 3 次还起不来，就先停下，等下次重启引擎再试。日志写「8788 被其他程序占用」，说明端口被别的程序占了。
- 连 li 或 li2 时某个模型报 400，说这个 Key 不允许该模型：到那台电脑的网关面板「设置 → API Key」，给对应的 key 在「允许模型」里加上它。li 上平板用的是「li-cn (国内版)」，11-26 已经加上 glm-5.4 和 kimi-k3.1-pro。
- 重跑装机脚本不会重新下载网关，也不碰账号。插件在 App 里被删了、想重新挂上，先删掉 `/root/liming-gateway/.added` 再跑。
- 只想看看脚本要做什么：`curl -fsSL https://liming-work.com/tablet/setup.sh | bash -s -- --dry-run`。
- 云端任务的台账在 `~/.liming-cloud/tasks.json`（只记任务号、机器、状态、结果摘要这些，不存对话内容），日志在 App 的引擎日志里，以 `liming-cloud` 开头。
- AI 说「没派出去」：照它说的理由看。常见的是两台都在冷却、两台都满了、`li2 还没装 SSH 令牌`（重跑装机脚本）。
- 状态条老是「状态未知」：那台没装只读 key，或者 key 被吊销了，重跑装机脚本补上。
- 云电脑上租约插件的日志在那台 dsh web 的日志里，以 `[liming-lease]` 开头。权限过宽的 `lease.key` 会被跳过，日志会提醒改回 600。

## 仓库里的文件

| 文件 | 是什么 |
|---|---|
| `site/tablet/setup.sh` | 装机脚本 |
| `site/tablet/liming-gateway/` | DSH 插件：网关跟着本机引擎启停 |
| `site/tablet/liming-cloud/` | DSH 插件（平板）：`cloud_run`、`cloud_tell`、`cloud_machines` 三个工具，状态条和「云端任务」面板，台账、停止、断线和重启后的对账 |
| `site/tablet/liming-lease/` | DSH 插件（li、li2）：平板派来的活在跑时持有 InstaBox 活动租约 |
| `site/tablet/dsh-tablet.sh` | 放到 li、li2 上的包装脚本：读本机网关 key，固定用 Harness 内置的 `web` 配置 |
| `site/tablet/dsh-tablet-profile.yml` | li、li2 上 `web` 配置的网关线路，由 `scripts/tablet-profile.mjs` 从天启的模型表生成 |

网关程序（WorkBuddy2API-Hub）和任何账号、key 都不进仓库，因为仓库是公开的。装机脚本只写死原版安装包的大小和 SHA-256。

这些文件单独发布：只改了 `site/tablet/`、`scripts/tablet-*`、`test/tablet-*` 和文档时，正式发布不跑小芯真模型联调（规则见 `scripts/xin-live-scope.cjs`）。
