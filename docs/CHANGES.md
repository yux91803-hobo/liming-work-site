1. `stm32.js` / `shell.js`：定位参数同步改为节流（单次操作下一帧，连续操作最多每 300ms 一次），replaceState 加保护。原来每翻一页课件写两次地址，按住方向键几秒即可超过浏览器频率上限（Safari 约 100 次 / 10 秒，超出抛 SecurityError），外壳子视图历史随之写入失败、返回键错乱。
2. `study-core.js`：全局搜索别名改为前缀展开（UART1 → USART1、IIC2 → I2C2、串口1 → USART1）；标题命中排在只在说明里命中之前；归一化文本按条目缓存；「PA 9」合并加词边界。
3. `learning.js`：寄存器索引补收 `GPIO_CRL`、`GPIOA_CRL`、`USART1_SR` 等常见写法（原来只能搜 `GPIOx_CRL`）。
4. `learning.js`：搜索框有字时 Esc 直接关闭对话框（浏览器默认第一次 Esc 只清空输入），与提示一致。
5. `snippets.js`：按键扫描在同一轮确认两个键时不再丢掉第二个；TIM6 中断示例启动前清 UIF，避免一启动立即进一次中断。
6. `stm32.js`：代码片段高亮结果按片段缓存，切换分类时克隆复用。

## 验证范围

- 11 项 Node 行为测试通过（新增搜索别名 / 排序用例）。
- Chromium 端到端 23 项全过、0 JS 报错：嵌入外壳连续翻课件 120 页后页码与外壳地址一致，返回依次关闭查看器、关闭工具；`?cw` / `?page` / `?reg` / `?q` 深链；课件跳代码 / 引脚；全局搜索；390px 触屏左滑翻页。
- 同一套测试对照 main：翻 120 页地址写入 240 次 → 34 次；快速输入 26 字 21 次 → 3 次。
- Key_Scan 用 gcc 编译模拟：两键同时按下，旧版只报 KEY1，新版 KEY1 / KEY3 各报一次。

# 修改清单 · 2026-10-26

## 修复

1. `regs.js`：局部修改后不再追加整寄存器赋值；完整赋值移到独立折叠区域。未选择任何字段时不生成隐式复位写入。
2. `regs.js`：只写/写 1 生效及写 0 清除分支不再连续输出两条等价写入；避免重复执行寄存器动作。
3. `regs.js`：常用 GPIO 配置按其 `port` 切换实例，避免 PF8 / PB10 等配置仍作用于 GPIOA。
4. `regs.js`：GPIO HAL 示例补上结构体与端口时钟使能；所有计算值注明未连接开发板。
5. `shell.js` / `stm32.js`：内嵌页面通过同源、来源窗口校验的消息同步白名单定位参数；保留原有 history.state 和子视图返回机制。
6. `stm32.js`：只有图片/封装缩放区拦截 Safari 手势，正文保留原生放大。

## 功能

- 新增 `study-core.js`：定位参数白名单、搜索排序和学习记录校验，无 DOM 依赖，可独立测试。
- 新增 `learning.js` / `learning.css`：统一搜索、当前位置分享、收藏、状态与笔记、JSON 导出及合并导入、字号及代码换行设置。
- 搜索寄存器索引按需加载；加载失败后保留其他结果，并支持重新打开重试。
- 资料查看器内可直接收藏、写笔记、分享；原生对话框负责焦点约束，避免与原查看器快捷键冲突。
- 用户文本以 textContent 呈现；导入数据经过字段校验，限制文件大小、条目数和笔记长度。
- 补齐原上传包缺失的 506 个声明图片资源，以及 8 个 STM32 数据脚本和 4 个应用图标。
- 增加无依赖预览服务、本地资源检查、关键行为回归测试和资源哈希清单。
