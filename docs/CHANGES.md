# 修改清单 · 2026-10-26

## 修复

1. `regs.js`：局部修改后不再追加整寄存器赋值；完整赋值移到独立折叠区域。未选择任何字段时不生成隐式复位写入。
2. `regs.js`：只写/写 1 生效及写 0 清除分支不再连续输出两条等价写入；避免重复执行寄存器动作。
3. `regs.js`：常用 GPIO 配置按其 `port` 切换实例，避免 PF8 / PB10 等配置仍作用于 GPIOA。
4. `regs.js`：GPIO HAL 示例补上结构体与端口时钟使能；所有计算值注明未连接开发板。
5. `shell.js` / `stm32.js`：内嵌页面通过同源、来源窗口校验的消息同步白名单定位参数；保留原有 history.state 和子视图返回机制。
6. `stm32.js`：只有图片/封装缩放区拦截 Safari 手势，正文保留原生放大。

## 功能

- 新增 `study-core.js`：定位参数白名单、搜索排序和学习记录校验，无 DOM 依赖，可独立测试。
- 新增 `learning.js` / `learning.css`：统一搜索、当前位置分享、收藏、状态与笔记、JSON 导出及合并导入、字号及代码换行设置。
- 搜索寄存器索引按需加载；加载失败后保留其他结果，并支持重新打开重试。
- 资料查看器内可直接收藏、写笔记、分享；原生对话框负责焦点约束，避免与原查看器快捷键冲突。
- 用户文本以 textContent 呈现；导入数据经过字段校验，限制文件大小、条目数和笔记长度。
- 补齐原上传包缺失的 506 个声明图片资源，以及 8 个 STM32 数据脚本和 4 个应用图标。
- 增加无依赖预览服务、本地资源检查、关键行为回归测试和资源哈希清单。
