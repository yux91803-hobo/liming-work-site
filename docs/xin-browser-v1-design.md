# 小芯浏览器 v1 第一步：公开网页（设计）

- 日期：北京时间 2026-11-12。站长同意「先收尾，再做浏览器 v1 第一步」。
- 依据：`docs/xin-next-stage.md` 第 5 节（定稿）、研究笔记第 5 节「浏览器」。
- 范围：**只做公开网页**——干净浏览器、不保存登录、用完即清。要登录的网站、确认卡片、「交还小芯」是第二步。

## 1. 现状和这一步加了什么

- 后台任务已经能上公网：容器里的命令经出网代理（只放行公网地址的 80/443）用 curl 之类取网页；Gemini（Antigravity）任务还自带 `search_web`、`read_url_content`。**查资料本身已经能做。**
- 做不到的：要执行 JavaScript 才有内容的页面、要在网站里搜索或一层层点进去才找得到的手册和下载、看页面实际长什么样（截图）。站长也看不到它在网上干什么。
- 这一步加：后台任务能用一个由控制器管着的真实 Chromium（`xin browser …` 命令），开在小芯电脑的桌面上，站长点「屏幕」能看。它也是第二步（登录网站）的底座。

## 2. 参考

- **Microsoft Playwright CLI / Playwright MCP**（`microsoft/playwright-cli`、`microsoft/playwright-mcp` 的 README）：
  - 给编程代理用命令行而不是 MCP（「不把大段工具说明和无障碍树塞进上下文，更省 token」）。
  - 页面用无障碍树快照表示，元素带编号（`e15`），`click e15`、`fill e15 文字` 按编号操作；每个命令只回网址、标题和快照。
  - 默认用内存里的临时资料（关了就没），空闲一段时间自己关。
  - 两个项目都写明「不是安全边界」：网站范围、本机地址这些限制要由外面一层（小芯的控制器）来管。
- **Grok Bot `tools/sand-browser-tools.ts`**（研究笔记）：快照里给元素编号；有后果的操作先检查；不让模型碰读写 cookie 的 CDP 命令（小芯这里干脆不给模型任何 CDP）。
- **OpenDuet `secret-masking.ts`**（研究笔记）：无障碍快照会把密码框的值明文报给模型，要打码。
- **小芯自己已有的**：网页成品检查（`WEB_BROWSER_CHECK`）已经在用电脑上的 `/usr/lib/chromium/chromium` 和 CDP；后台容器经控制器的 unix socket 转发出网和模型（`taskNetwork`、`TASK_FORWARDER`）。

## 3. 结构

```
后台模型（容器里）                    控制器（容器外，这一轮的 runner 进程）
  xin browser open https://…  ──HTTP──▶ 127.0.0.1:18082 ─转发─▶ browser.sock ─▶ 浏览器代理（vm-browser.mjs）
                                                                                 │ CDP（管道，不开端口）
                                                                                 ▼
                                                                  Chromium（桌面上，干净资料）
                                                                                 │ --proxy-server
                                                                                 ▼
                                                                  出网代理（只放行公网地址的 80/443）
```

- **浏览器代理**跟着每一轮任务的网络（`taskNetwork`）起、跟着它关：容器多转发一个端口 `TASK_PORTS.browser = 18082` 到这一轮自己的 `browser.sock`（目录控制器所有、容器里只读，和出网、模型同一套）。只有这一轮的容器连得到，不另发令牌。
- **Chromium 第一次用到才启动**（不浏览的任务不多开进程）。`--remote-debugging-pipe`：CDP 走管道，不开调试端口，电脑上别的进程接不上。资料目录在容器看不到的地方（`xin-task-<任务>/browser-profile`），这一轮结束连进程带资料一起删。
- **网络**：Chromium 的所有请求走一个只听 127.0.0.1 的出网代理（同一个 `egressProxy`，只放行公网地址的 80/443；`--proxy-bypass-list=<-loopback>` 让本机地址也走代理、被拒）。本机的网关、模型代理、云电脑元数据地址都打不开。只认 `http:`、`https:`；`file:`、`chrome:`、`data:` 之类网址直接拒。
- **显示**：电脑有桌面（`screenDisplay()`）就开在桌面上，站长点「屏幕」能看；测试和没有桌面时无头运行。「小芯在干什么」终端里同样一行一行记它打开了什么、点了什么。

## 4. 命令（给后台模型）

照 Playwright CLI 的样子，少而够用：

| 命令 | 做什么 |
|---|---|
| `xin browser open <网址>` | 打开网页（第一次用时启动浏览器） |
| `xin browser snapshot` | 当前页面的无障碍树，元素带编号 `e1`、`e2`… |
| `xin browser click <编号>` | 点一下 |
| `xin browser fill <编号> <文字>` | 在输入框里填文字（先清空） |
| `xin browser press <按键>` | 按键，比如 `Enter`、`ArrowDown` |
| `xin browser select <编号> <选项>` | 下拉框选一项 |
| `xin browser scroll [down\|up]` | 翻一屏 |
| `xin browser back` | 后退 |
| `xin browser text [编号]` | 页面（或某个元素）的正文文字，读文章、手册用 |
| `xin browser screenshot [文件名]` | 截图存进任务副本，给能看图的模型看、给站长看 |
| `xin browser tabs` / `tab <序号>` | 列出、切换标签页（点开新窗口时自动切过去） |
| `xin browser close` | 关掉浏览器 |

- 每个操作后回：网址、标题、新的快照（太长截断，提示用 `text` 读正文）。编号只在最近一次快照里有效；页面变了还用旧编号会被拒，提示先 `snapshot`。
- 快照里密码框只写「密码框」，不给值；也不给隐藏元素。
- 下载的文件进任务副本的 `downloads/`（单个 100 MB 以内），做完和别的结果一起写回。

## 5. 哪些不做（第一步）

按 `docs/xin-next-stage.md` 5.3 的等级，由代理按页面元素自己判断，不信模型说的意图：

- **自主完成**：打开、浏览、搜索、翻页、读正文、截图、下载公开资料。
- **第一步直接拒绝，告诉模型「把要做的事写进结果交给站长」**：
  - 往密码框、银行卡号这类框里填东西（要登录、要付款的是第二步）；
  - 点会产生外部后果的按钮或链接：名字像付款 / 购买 / 下单、删除、发送 / 发布 / 评论 / 回复、登录 / 注册、授权 / 允许、订阅 / 关注；
  - 在这类表单里按回车提交。搜索框（`type=search`、`role=search`、按钮叫搜索 / Search / 查找）照常。
- 上传文件、读写 cookie、执行任意脚本：不提供。
- **预算**：每轮最多 300 个浏览器命令、最多 5 个标签页、每个命令 30 秒、快照最多 1.2 万字；超了就拒并说明。
- **记录**：每个命令记进这一轮的过程（任务详情里能看到「打开网页 …」「点击 …」），也写进「小芯在干什么」终端。

## 6. 谁能用

- 在容器里跑的后台任务（Codex 和 Antigravity 两种执行入口都经 `taskNetwork`），只要这一轮开了网络就有。
- 前台聊天不直接开浏览器：要上网操作就派任务（和现在一样）。
- 后台任务的提示词加几行：什么时候用（要点、要执行脚本、要截图的网页；只读文字的继续用 curl / `read_url_content` 更快），命令怎么用，哪些会被拒。

## 7. 测试

- 单元测试用真的 Chromium（本机 `CHROMIUM_PATH`、CI 上的 Chrome）打开测试服务器上的页面；测试里放行本机地址（只在测试参数里，正式不开）：
  - 打开、快照带编号、点击后跳转、填写加回车搜索、翻页、后退、正文、截图文件、新窗口自动切过去；
  - 旧编号被拒；密码框不出值、往里填被拒；「删除」「发送」「登录」按钮被拒，「搜索」照常；
  - `file:`、`chrome:` 网址被拒；本机地址（正式的地址检查）打不开；
  - 预算用完被拒；一轮结束浏览器进程和资料目录都没了。
- 容器里 `xin browser` 经转发端口连到代理（沿用现有容器测试的做法）。
- 正式站联调先不加真实上网操作（外网网页不稳定）；上线后找一个真实任务试一次，结果写进修改清单。

## 8. 不在这一步

- 保存登录、白名单网站、遇到登录框停下等站长接管（第二步）。
- 确认卡片（附截图）和「任务内授权」（第二步）。
- 「网站做法」（成功流程存起来下次照做）、已执行动作账本（第二步有后果的操作才需要）。
- 桌面软件操作。
