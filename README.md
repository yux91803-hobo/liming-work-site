## 世界地图有什么

- 矢量、高德、卫星、高德卫星四种底图，支持搜索、定位、缩放、指北和点选国家；矢量地图默认视角就显示主要省州名称与省界，省名优先于相邻城市排布，放大后补充更多细节。高德与其他底图切换时，相机和标记同时转换坐标，保持原来的位置。
- 搜索结果支持方向键、Enter 和 Esc；改字、清空或点地图会取消旧搜索，迟到的结果不会覆盖新的操作。在线搜索失败时仍可查本地国家数据，跨日界线的国家也能正确聚焦。
- 矢量瓦片或样式加载失败时临时使用高德，不覆盖保存的底图偏好；浅色、深色跟随工具箱，深色地名保持清晰对比，细节随缩放出现。图层面板支持键盘与下滑关闭，手机允许浏览器缩放。

## STM32 学习台有什么

- **首页**：STM32F103ZET6 芯片引脚图（双击 / 双指放大），按分组列出开发板上的模块；点引脚看复用功能和板上接到哪里。
- **开发板**：原理图逐页翻看，22 个模块图，点脚看连接和作用。
- **外设页**（RCC、GPIO、EXTI、USART、I2C、TIM、DMA、ADC、SPI、FSMC）：要点 / 引脚 / 寄存器 / 代码 / 图。
  - 寄存器：位图计算器，点位改值，生成读-改-写代码和 HAL 写法，常用配置一键填好；I²C 时钟助手检查 STM32F103 的频率范围，CCR 向上取整以免超速，并显示实际 SCL，修改 DUTY 后同步重算。
  - 代码：完整的 .h / .c / main.c（寄存器版、HAL 版）和「代码推导」，可以「自己写」逐行练。
  - 图：参考手册框图、课件教学图，点开大图查看。
- **编程思维**（GPIO、定时器）：明确任务 → 查资料 → 规划 → 编写 → 验证五步；验证里粘贴自己写的函数，模拟器跑一遍指出问题。
- **硬件原理**：每个外设一张自绘结构图，按块讲解；I2C 等章节有「推导链」自主推导题。
- **搜索**：Ctrl/Cmd+K 或右上角，搜引脚、寄存器、代码、图；改词后立即回车也按最新输入定位，Tab 能到取消，方向键选择的结果会告知读屏。搜索、寄存器和看图叠开时只有最上层可操作，最后一层关闭后恢复滚动。
- **操作状态**：从任意代码模式都能切到要点、引脚、寄存器和图，切回来保留代码模式、驱动与文件；切换文件立即同步到地址，查寄存器、看图后逐层返回原文件和阅读位置。手机目录、搜索也计入返回层级，返回先关闭当前临时层，再退页面。
- **主题**：浅色、深色切换时，当前外设、引脚高亮和寄存器标签即时更新颜色，保留正在编辑或计算的内容；异常寄存器、模块链接也不会阻止页面加载。
- **返回**：返回键、浏览器 / 手机的返回按走过的路一层层退回；去的页面已经走过（GPIO → USART → GPIO），就直接退回到那里，返回时不会在同几页之间来回打转；同一页里换分页不算一层；回学习台首页就清空。电脑（宽屏）上返回键旁边一直有「回工具箱」；直接打开学习台时，左上角的「STM32F103 学习台」也能点回工具箱。

## 天启

从工具箱首页打开「天启」，或直接访问 `/tianqi`。天启与小芯共用网站登录，拥有独立的云电脑、对话记录、待送达队列和内核连接。直接打开天启只唤醒 `li2`，回到首页再唤醒小芯。`li2` 上使用 Harness，系统提示词只有「你叫天启。」，支持选择网关模型和思考强度。

给天启上传 PNG、JPEG、WebP 或 GIF 后，可以让 DeepSeek V4.1 Flash、GLM-5.3 或 Kimi K3.1 Pro 用 Harness 的读图工具查看附件。GLM-5.3 Flash 只处理文字。

天启工作台照 DeepSeek Harness 桌面端分三栏，样子照 Linear 改得克制：三块实心面板放在夜空上（深色夜空、浅色星图，在设置里换；进了对话夜空暗一点），只留金色一种点缀色，用系统字体。左栏是对话记录、设置和插件，Ctrl+B 收成窄条；中间顶栏是「工作区 / 标题」，下面是对话和输入框；右栏是文件、终端、预览，Ctrl+J 收起。Ctrl+K 打开命令面板，天启的常用操作都在里面、右边写快捷键；没在打字时单键 C 新对话、M 换模型、P 换权限、W 换工作区。插件页电脑上居中、手机上从底部升起。天启跑命令时右栏自动换到终端跟着看；文件里的图、网页、markdown 和回答里提到的这类路径能在「预览」里打开。宽度不到 1200 时右栏浮在聊天上，不到 900 时左栏是抽屉，手机上右栏从底下升起。输入框里能选这个对话的权限（只读、工作区内修改、完全权限，默认完全权限，设置里改新对话的默认），沙箱用 li2 内核的 Landlock；也能开计划模式：那一轮天启只读、只出计划，对话里一张计划卡片、右栏「计划」放全文，点「按计划执行」再按对话的权限动手。每个对话有自己的工作区：新对话时在输入框上面选 `/data/workspace` 本身或它下面一层的文件夹（也能新建），对话开始后固定，标题旁显示，左栏按工作区分组。右栏「终端」底下能自己输命令，在这个对话的工作区里跑，最多 60 秒、输出最多 64 KB。 [v4 设计](docs/superpowers/specs/2026-11-19-tianqi-harness-workbench-design.md)

REA 开启时通过 MCP 兼容桥转换当前网关不接受的 pattern `allOf` 广告约束；工具与实际调用不删减，原服务继续验证参数。

新站点需配置 `li2` 的 InstaBox key、Harness 和独立网关账号，再验收真实回话。已有天启对话仍在小芯工作台，通过 `li` 继续。 [天启设计与验收条件](docs/superpowers/specs/2026-11-18-tianqi-li2-design.md)

## 小芯后台运行方式

- 后台通过 Codex app-server 管理轮次。「立即补充」送入当前轮次；默认排队消息逐条发送，刷新可恢复，重试携带稳定消息编号。
- **后台干活时插话**（2026-11-17）：在原聊天里随口补一句（「刚才查模型那件事，备用的别列」），小芯认出是哪件事转过去。Codex 任务经 `turn/steer`、Gemini 后台在每一步之间把补充放进下一次请求，回话按实际接法说一次（「行，最后只给你列正在用的」/「这轮跑完我就按你补的范围再核一遍」）。做完或停了的事先说状态，明确说继续才接着做。补充在超时、断线、重启、停下、换模型后都带到下一轮，同一编号只算一次。只有兄弟这句像在补充、改主意、要停或要接着做时，前台才看得到 `<手上的事>`，平时不列进行中。
- **后台主动回来说一句**：发现会改变结论的事、碰到会改变计划的阻塞时，后台用 `xin task note`（Gemini 用 `action=note`）说一句，接着做；20 秒内相关的合成一条，每件事最多 3 条；最终结果先到了就不发。这句直接记进原聊天（不调模型、不推送），终端里也看得到兄弟的补充和这句。
- 切换对话会作废旧页面回调，旧发送结果保留在原会话；未提交成功的旧消息可从侧栏「未发送的消息」恢复。后台提问收到快速答复后同步消费旧问题，后续新问题照常保留。
- 后台任务在独立文件系统、PID 和网络容器中运行，只能写项目副本及私有 home/tmp/io。容器看不到小芯电脑上的本机服务（桌面、模型网关等）：推理经控制器的套接字代理，上网经出网代理且只能访问公网的 80/443，编译、网页验收和插件不联网。控制目录和宿主进程不映射；长期网关密钥只在控制器，容器使用限模型、限接口、限次数的临时推理凭证。首次配置云电脑运行 `scripts/vm/setup-xin-runtime.sh`；已在 Codex 0.166.0 / bubblewrap 0.12.0 上验证。
- **电脑维护**（`--kind system`）：检查磁盘、修服务、装软件等任务直接在小芯电脑上运行，可以使用 sudo。已登录站长当轮发话并按原话派发时，可以直接开工。自动续做或缺少授权来源时，在任务详情批准这次维护才开工。批准绑定本次任务、目标、目录和补充，30 分钟内有效。删站长的文件、花钱、对外发消息、删机器或快照、重启整台电脑仍需要先问。维护任务按 `WORK/system` 串行执行。`instabox-guest-agent` 和 `workbuddy-gateway` 保持运行，控制器目录只读。 [宿主授权设计](docs/superpowers/specs/2026-11-14-xin-kernel-stage2-design.md)
- 普通改动备份后写回；删除原文件或覆盖任务期间的改动，要点「允许这一次 / 拒绝」。写回写到一半出错会按清单从备份还原原项目；写回到一半被杀，下次收尾把已写回的算完成、补齐剩下的，不误报冲突。中断、停止和失败会保留副本供续接。同一项目及嵌套目录仍串行执行；没有引入并行 worktree。
- 任务副本放在控制器旁边的 `~/.xin-tasks/`（不在系统临时目录，免得被 InstaBox 的 10 天清理删掉一部分）。做完的任务副本 7 天后在每日清理时删（结果已写回项目，写回前的备份留 30 天）；没做成、停了、等确认的留到删对话为止。做完时记下用量，删了副本也照样显示。
- 干活中途遇到临时错误（断线、网关 5xx、限流），控制器分别等 1、4、15 分钟用同一个副本和会话接着做，卡片写「连接出错，稍后重试」（首页小卡片写「稍后重试」）；预算用完、超时等照旧算没做成。时限从第一次开工算，不因重试延长。
- 后台中途问你问题，等 10 分钟没回就记成「待处理」、结束这一轮，云电脑可以睡；你回答后接着同一个会话做。
- 「待处理」只剩三种：要批准的操作（删你的数据、推 main、部署、花钱、对外发消息、写回时删文件或覆盖冲突）、登录、提问；最多等 30 分钟，过了任务自己停下（结果里写明当时问的什么），不再提醒，之后回一句照样接着做。能自己定的不问，做不了直接结束说原因；中途断了两次、复核找不到模型直接算没做成。工作台和首页显示「剩 N 分钟」。
- 需要静态逆向分析时，派任务加 `--plugin rea`，只开放明确列出的分析接口。MCP 与模型工具都在同一容器里，不能改控制器或设备。
- 请求预算默认每任务 128 次及 150 万已报告输入加输出 token，跨续接/恢复和完成推理累计；后台默认 60 分钟、并发 2，不擅自降低 max。实际 token 记录用于后续比较，不把请求数当成人民币费用限额。
- 任务索引由状态进程按任务事务更新，结束任务压成摘要，完整历史按需读取，不自动删除。用户原话单独传给作者和检查者，避免前台转述成为唯一依据。
- 常驻状态进程与 Cloudflare 持久 alarm 在网页关闭后继续监督任务、重试通知和更新活动租约。进程恢复先清理遗留子进程、检查已完成步骤；停止后等实际退出才释放目录。每日任务进入同一个调度器，用自己的目录 `/data/workspace/daily`，跑的时候不挡别的后台任务。
- 状态进程处理请求前先恢复待补写的投影；网页取进度带上次读到的字节位置，只读新增的部分。
- STM32 实现任务由控制器对最终源码强制重编译并检查本次生成的有效 HEX / ARM ELF / BIN；支持根目录或嵌套 Make/CMake 工程，多个入口用根目录 `xin-build.json` 指定 `system`、`directory` 和可选 `artifacts`，无法识别时明确失败。检查任务另写 `xin-review.json`，逐项记录时钟、引脚/复用、外设时钟和中断的手册依据、源码位置与结论。编译和静态检查不能代替上板验证。
- 推送按设备和标签页识别是否正在看同一对话；电脑在看不会压掉手机，旧订阅没有设备标识时照常投递。通知出站记录有版本和回执，过期响应不删除新订阅。
- 后台桥固定 io 目录句柄，请求按 fd 校验读取，回复用独占临时文件写完再原子发布，不跟随软链接或覆盖已有条目。进程清理检查整个任务 session，组长先退出或孙进程更换进程组也须清理完才释放目录，使用 pidfd 防止 PID 复用。
- Codex 原生分身显式关闭，派工只通过小芯统一任务调度；后台分身不能再次派工。
- 全部 16 项的结论与证据见 [走查表](docs/XIN-REVIEW-16.md)。
- InstaBox 免费机的强制运行上限仍由平台控制，冷却期间 alarm 会等待再唤醒。Web Push 的投递回执不等于手机已经显示通知。

## 本地运行

需要 Node.js 20 或更新版本。静态预览和单元测试不需要安装依赖。

```sh
npm run dev        # 本地预览
npm run check      # 语法、本地引用、STM32 图片引用 + 单元测试（小芯控制器测试都对着真的状态进程跑）
npm run test:e2e   # 浏览器端到端测试（需要 Python playwright + Chromium，先 npm run dev）
```

`npm run check` 起的测试碰不到这台机器上的 systemd（`scripts/test-env.mjs` 把 `XIN_SYSTEMD_BUS` 指到不存在的路径）。在有用户会话的机器上（GitHub 托管机器就有）直接用 `node --test` 跑单个小芯测试时，自己带上 `XIN_SYSTEMD_BUS=/nonexistent/xin-tests-no-user-session/bus`。

`/stm32` 使用与正式站一致的工具箱外壳；也可以直接打开 `/tools/stm32/`。

同一对话的发送、改名、归档、删除和后台状态更新由状态进程处理。两个设备同时发送时，后一个会明确提示上一句未完成，避免漏记历史。自动清理只处理 `~/.xin/agent-sessions/` 登记过、已没有网页对话关联且超过一小时未更新的 AI 记录：现有网页对话会自动补登记，其他命令行任务和无法确认归属的旧记录保留。75 秒自动重连只用于尚未开始工作的 CLI：收到任务开始或模型进展后，不再由网页重放这一轮，长思考期间暂时没有输出也不会被网页打断；后续网络超时和重试交给 CLI 自己处理，手动停止照常可用。
