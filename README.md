# Liming 工具箱 · STM32 学习工作台

自己学嵌入式用的网站，电脑、平板、手机都会用。工具箱有两个工具：STM32 学习台、世界地图。

## 世界地图有什么

- 矢量、高德、卫星、高德卫星四种底图，支持搜索、定位、缩放、指北和点选国家；矢量地图默认视角就显示主要省州名称与省界，省名优先于相邻城市排布，放大后补充更多细节。高德与其他底图切换时，相机和标记同时转换坐标，保持原来的位置。
- 搜索结果支持方向键、Enter 和 Esc；改字、清空或点地图会取消旧搜索，迟到的结果不会覆盖新的操作。在线搜索失败时仍可查本地国家数据，跨日界线的国家也能正确聚焦。
- 矢量瓦片或样式加载失败时临时使用高德，不覆盖保存的底图偏好；浅色、深色跟随工具箱，深色地名保持清晰对比，细节随缩放出现。图层面板支持键盘与下滑关闭，手机允许浏览器缩放。

## STM32 学习台有什么

- **首页**：STM32F103ZET6 芯片引脚图（双击 / 双指放大），按分组列出开发板上的模块；点引脚看复用功能和板上接到哪里。
- **开发板**：原理图逐页翻看，22 个模块图，点脚看连接和作用。
- **外设页**（RCC、GPIO、EXTI、USART、I2C、TIM、DMA、ADC、SPI、FSMC）：要点 / 引脚 / 寄存器 / 代码 / 图。
  - 寄存器：位图计算器，点位改值，生成读-改-写代码和 HAL 写法，常用配置一键填好。
  - 代码：完整的 .h / .c / main.c（寄存器版、HAL 版）和「代码推导」，可以「自己写」逐行练。
  - 图：参考手册框图、课件教学图，点开大图查看。
- **编程思维**（GPIO、定时器）：明确任务 → 查资料 → 规划 → 编写 → 验证五步；验证里粘贴自己写的函数，模拟器跑一遍指出问题。
- **硬件原理**：每个外设一张自绘结构图，按块讲解；I2C 等章节有「推导链」自主推导题。
- **搜索**：Ctrl/Cmd+K 或右上角，搜引脚、寄存器、代码、图。
- **返回**：返回键、浏览器 / 手机的返回按走过的路一层层退回；去的页面已经走过（GPIO → USART → GPIO），就直接退回到那里，返回时不会在同几页之间来回打转；同一页里换分页不算一层；回学习台首页就清空。电脑（宽屏）上返回键旁边一直有「回工具箱」；直接打开学习台时，左上角的「STM32F103 学习台」也能点回工具箱。
- **小芯**：首页的像素小助手，按参考图重画为黑色倒角芯片、银白顶边与中央凹口、暖金属引脚、四条小腿；常态双手对称平伸，举手只在动作中出现；常态直接采用图中的专注眼：较宽、略带圆角的暖白发光竖矩形，没有腮红；只有微笑、开心和喜欢时出现淡淡的双斜杠腮红，`> <` 只用于微笑。微笑、专注、开心、冷静、星星眼和爱心眼均可由聊天指令和自编动作触发，表情结束后恢复常态，保留眨眼；生气用连贯内压斜眉和半眯眼，聊天头像和收起的小脑袋也使用同一套造型。可以拖、喂、玩。拖到 STM32 卡片上松手，它就跟进学习台；学习台里背包点「收起来」，它躲到屏幕右边只露个小脑袋，点小脑袋又跳回来（刷新也还收着，下次再把它扔进来就出来）。
- **小芯聊天**（只给站长自己用，要登录）：小芯的「大脑」是 InstaBox 云电脑里的 Claude Code / Codex。小芯背包里点「聊天」，小芯旁边冒一个输入框（打字或语音），回复出现在小芯头上的气泡里，点气泡或「展开」打开面板看全文和历史（地址后面加 `#xin` 直接打开面板，没登录先要密码）；它能在云电脑里写代码、编译、跑命令。面板像聊天软件（不用首页的像素风：系统字体、圆角气泡、圆角输入框和柔和阴影，只有小芯自己还是像素画）：小芯在左边（像素头像、白底圆角气泡），你在右边；它在电脑上执行的命令不显示，你发出去以后小芯那边冒一个「正在输入」的气泡，旁边写着：接收中（消息还在送到它电脑的路上，电脑在睡就写唤醒中）→ 思考中 / 在电脑上忙，和从消息送到那一刻起过了几秒（每秒走）；回答里的列表、表格、代码块都排好版（代码上色，能一键复制）。面板标题栏的「屏幕」全屏打开小芯电脑的桌面（InstaBox 的桌面链接）：桌面上有个「小芯在干什么」终端实时滚动它执行的命令和结果；默认只看，点「接管」就能用自己的鼠标键盘操作它的电脑，关掉时接管用过的链接全部作废。小芯跟着动：AI 在想就坐在电脑前挠头，执行命令就敲键盘，做完开心、失败难过；AI 也能用 `xin dance`、`xin say 搞定啦` 这类命令直接指挥小芯。新对话用哪个 AI（Codex / Claude）、思考强度（自动 / 高 / 最高，自动时写代码、编译、调试这类活用最高）在侧边栏（面板左上角 ☰ 拉开）最下面的「设置」里选。登录后打开网页就会叫醒小芯的电脑（云电脑空闲 30 分钟会自己睡）。小芯的设定是：自己就是小芯，有一台自己的电脑，不说背后的模型和平台。它有长期记忆：一本自己的记事本，聊天时了解到的事会自己记下来，侧边栏里「小芯的记事本」能看能改。它还有每日任务：每天北京时间 9:10 按清单干活（8:55 先叫醒电脑让网关 9:00 自己签到；没做成 21:10 再来），结果会在你下次打开网页时说给你听；侧边栏里「每日任务」能看能改。发消息时会自动附上你正在看的学习台页面、划选的文字和「验证」里写的代码（输入框上面写着「附带：…」；点 ✕ 以后在这一页上一直不带，发完也不再冒出来，换到别的页面或者又选中了新的文字才再出来；侧边栏「设置」里能把「附带正在看的页面」整个关掉）。小芯的电脑里装好了 STM32 编译环境（`arm-none-eabi-gcc` + STM32F103ZET6 空工程，和学习台一样写 `#include "stm32f10x.h"`），让它「写个点灯程序编译成 .hex」就行；侧边栏里「小芯的文件」能浏览它电脑里 `/data/workspace` 的文件、预览文字文件、下载 .hex / .bin，回答里的 `/data/workspace/…` 路径点一下也能打开。输入框底下一行小字是这个对话的用量：上下文用了多少（最近一次请求占模型上限的百分比，带一根小进度条，70% 以上变陶土色、90% 以上变红）、累计消耗多少 token、缓存命中率（输入里有多少是缓存命中的），点一下展开明细（上下文多少 / 上限、输入、其中缓存命中、输出）；每轮做完更新，新对话还没有就不显示。输入框左边的「＋」：①「图片或文件」——拍照、相册、文件都行，选了马上传到小芯电脑的 `/data/workspace/uploads/日期/` 下面（输入框上面一排显示，带进度，能 ✕ 去掉；图片太大先在手机上压到长边 2048），传完才能发；发出去的消息里图片显示缩略图（点开看大图）、文件是小卡片（点开在「小芯的文件」里预览、下载）；小芯那边 Codex 直接看图片，别的文件把路径给它自己读；电脑上也能直接粘贴图片、把文件拖进面板。一次最多 10 个、每个 100 MB 以内。②「插件」——列出你自己给小芯装的插件（Codex 的 MCP 服务器，比如 REA 逆向；电脑自带的 InstaBox、操作桌面是基础能力，一直开着，不显示）和开没开，点开关从下一句开始生效（每一句都重新起一次 AI，同一个对话里也能切换）；开着的插件每句话都要带上它的说明书、很费 token，用不上就关掉。小芯自己也能用 `xin plugin on/off 名字` 开关。侧边栏的对话列表只露最近 5 个（正在看的那个不管排第几都露着），其余收在「更多对话（N）」里，点开看全部、再点收起。每个对话后面的 ⋯ 能改名、归档、删除（归档：收进列表最下面的「已归档（N）」里，默认收着，记录都留着，点开还能看、接着聊，那里的 ⋯ 能取消归档；删除要点两下；删的时候连小芯电脑里 Codex / Claude 自己存的那份会话记录一起删，没有对应对话的旧记录也顺手清掉，每日任务时也会清一次，不白占地方）。侧边栏的设置里还有「做完提醒」：打开后，关掉网页或切到别的应用时小芯做完了会发一条通知，点通知直接打开那段对话（iPhone / iPad 要先把网站添加到主屏幕、从主屏幕打开才能开）。小芯会自己编新动作（`xin move add`，一串姿势帧），打开网页时教给页面上的小芯：背包里「新动作」挨个做，闲着时偶尔做一个，聊天时它也会让你看。它还有好感度：聊天、每天来看它、喂它陪它玩会涨（每样每天有上限），它自己觉得被暖到 / 被凶了也会加减；好久不来会掉。关系分四级（刚认识、熟悉、好朋友、最好的朋友），越熟说话越随意、越不叛逆；侧边栏上面显示关系和最近的变化。

推导进度、粘贴的代码等只存在当前浏览器里，不跨设备同步。寄存器页面是计算器，没有连接真实开发板。

## 本地运行

需要 Node.js 20 或更新版本。静态预览和单元测试不需要安装依赖。

```sh
npm run dev        # 本地预览
npm run check      # 语法、本地引用、STM32 图片引用 + 单元测试
npm run test:e2e   # 浏览器端到端测试（需要 Python playwright + Chromium，先 npm run dev）
```

`/stm32` 使用与正式站一致的工具箱外壳；也可以直接打开 `/tools/stm32/`。

## 部署

由 GitHub Actions（`.github/workflows/deploy.yml`）完成，令牌在仓库 Secrets 里：

- 开 PR 到 `main`：检查通过后部署测试站 `liming-hub-staging`（只有 `*.workers.dev` 地址），并检查首页和 `/tools/stm32/`。
- 合并到 `main`：部署正式站 `liming-worldmap`（liming-work.com）；检查失败自动回滚到上一版。
- Actions 页面可以手动运行，默认只 dry-run。

### 小芯聊天要配的东西

| 放在哪 | 名字 | 是什么 |
|---|---|---|
| GitHub 仓库 Secrets | `XIN_OWNER_PASSWORD` | 网站登录密码，至少 12 位 |
| GitHub 仓库 Secrets | `XIN_INSTABOX_API_KEY` | InstaBox 的 API key（`ibk_…`） |
| 云电脑里 | AI 的 key | Codex / Claude Code 自己的登录或 key；推荐用 InstaBox 后台的 Secrets（代理模式），云电脑里只看到占位符 |

两个 GitHub Secrets 都配了，合并到 `main` 时 Actions 才把它们写进正式站（测试站不写，功能关着）。正式站还有两个定时任务（`wrangler.jsonc` 的 `triggers.crons`，UTC）：`55 0 * * *` 叫醒云电脑，`10 1,13 * * *` 让小芯做每日任务；测试站没有。云电脑默认找名字叫 `li` 的那台（`wrangler.jsonc` 里的 `XIN_MACHINE`）。
云电脑里的管理脚本 `vm-agent.mjs` 不用手动装：网站第一次用、或者脚本改过时，会自动传到 `/data/home/.xin/agent/`。对话记录存在云电脑的 `/data/home/.xin/`，AI 的工作目录是 `/data/workspace`（网站上「小芯的文件」只能看、只能下载这里面的）。
同一对话的发送、改名、归档、删除和后台状态更新用 Linux 的 `flock` 串行处理（InstaBox 的 Debian 镜像自带）；两个设备同时发送时，后一个会明确提示上一句未完成，避免漏记历史。自动清理只处理 `~/.xin/agent-sessions/` 登记过、已没有网页对话关联且超过一小时未更新的 AI 记录：现有网页对话会自动补登记，其他命令行任务和无法确认归属的旧记录保留。75 秒自动重连只用于尚未开始工作的 CLI：收到任务开始或模型进展后，不再由网页重放这一轮，长思考期间暂时没有输出也不会被网页打断；后续网络超时和重试交给 CLI 自己处理，手动停止照常可用。
STM32 编译环境用 `scripts/vm/setup-stm32.sh` 装（已经装好；换了新的云电脑就把它传到 `/data/home/.xin/setup-stm32.sh` 跑一次）：装 `gcc-arm-none-eabi`，从 ST、ARM 官方仓库下固定版本的 CMSIS 头文件和启动文件，在 `/data/workspace/stm32-template` 放一个能直接 `make` 的空工程（链接脚本按 ZET6：Flash 512K、RAM 64K；`syscalls.c` 让 printf / malloc 能链接）。可以重复跑，不会覆盖自己改过的 `main.c`。
AI 在云电脑里是完全放权的（不经确认就执行命令），云电脑里别放重要的东西，也别放 InstaBox key。
做完提醒用的是标准 Web Push：VAPID 钥匙在云电脑的 `/data/home/.xin/push/vapid.json` 里生成（私钥不离开云电脑，文件只有自己能读），浏览器的订阅存在同目录的 `subs.json`，推送从云电脑直接发给浏览器厂商的推送服务；网站只多了一个 `/sw.js`（只管弹通知，不拦截任何请求）。

互传和协作中心删除时留下的 Cloudflare 资源（迁移 `v2` 已在两个站执行过）：D1 数据库 `liming-hub` 还在账号里，确认不要可以 `npx wrangler d1 delete liming-hub`；旧密钥 `TRANSFER_PASSWORD`、`TRANSFER_KEY`、`TRANSFER_PW_VERSION` 可以用 `npx wrangler secret delete <名字>` 删掉。
